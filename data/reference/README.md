# 参考词表

这里放的不是词库，而是给 `scripts/import-typewords.mjs` 做**分档判断**用的参考数据。

## common-words-a.json / common-words-b.json

- **内容**：各约 1,200 条英语最常用词（词元、小写 ASCII），合并去重后 **1,836 条**。
  A 偏口语与日常，B 偏书面（新闻 / 非虚构 / 商务 / 学术）。
- **来源**：**由模型生成的**，不是权威词频表。它只用于回答一个成员判断：
  「这个词是不是常见到不必默认标注」——单条判断出错的影响很小（某个词标或不标），
  但不要把它当作词频排序来引用。
- **用途**：`--common=` 指定的词在导入时会被标成 `basic` 档（默认不标注），
  其余保留原难度。这样把整表 CET-4 并进来时，不会让 `ability`、`action`、`account`
  这类词把页面糊满中文。
- **想换成真实词频表**：把 COCA / BNC 之类的前 N 千词表导出成字符串数组，
  放到这里并改 `--common=` 的路径即可，脚本只要求 `^[a-z]+$` 的字符串数组。
  换表后请重跑 `npm run bench -- --levels` 复核阅读密度，并按结果调整默认生词线。
