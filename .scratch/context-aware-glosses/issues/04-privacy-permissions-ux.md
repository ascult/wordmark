## Question

这套**已经写好**的本机打分器通路，在默认姿态、端点白名单与对外说法上怎么收口？

代码现状（`src/core/settings.ts:94`、`src/options/options.ts:320`、`src/manifest.json:42`）：
- **默认关闭**（`sense.enabled: false`），注释理由是「整句会发到 endpoint，属于隐私敏感行为，
  必须由用户显式打开」——**与用户先前拍下的「默认开」相反**，必须重新裁决。
- 端点校验 `originOfLocalEndpoint`：明文 http 只允许本机 host（`LOCAL_HOSTS`），但 **https 不限**，
  也就是「只允许本地网络」这条承诺**目前并没有在代码里守住**。
- `optional_host_permissions` 已有 `http://127.0.0.1/*` 与 `http://localhost/*`；局域网 IP 无 CIDR 写法，
  需字面量或 `http://*/*`。

要定：

- **默认姿态**：默认关（现状）还是默认开？
- **https 远端是否允许**：允许就等于放开「只允许本地网络」；不允许则要改 `originOfLocalEndpoint`。
- 设置页那节草稿写的是「不发往任何第三方」——放开 https 时这句话就不成立了，文案怎么改。
- 首次启用的说明放哪、怎么写。**静默回退**（实现已「永不抛错、拿不到就保持词典义」）确认为终态。
- README 明写「默认纯离线、3,039 条内置词表、不发任何网络请求」——怎么改写；是否新增 ADR。
- 弹窗是否显示「语境义：开 / 不可达」。

闭票时给出：默认姿态 + 端点白名单规则 + 文案 + README/ADR 改法。

## Answer

用户委托我决策。

**1) 默认姿态 = 保持默认关闭（不改代码现状，**推翻**用户先前 Q3 的「默认开」）。**
理由：这不像词级在线兜底，它发的是**整句正文**，属另一量级；而且默认开时用户还没跑起服务，
这个开关本来就是空的。代码注释与 223 个用例都按「显式开启」写的。若你仍要默认开，一句话我就翻过来。

**2) 端点白名单 = 本机与局域网，http/https 同等对待。**
允许：`localhost`、`127.0.0.0/8`、`::1`、`10/8`、`172.16/12`、`192.168/16`、`169.254/16`、
IPv6 ULA `fc00::/7`，以及 `.local` / `.home.arpa` 结尾的主机名。其余（公网域名、公网 IP）一律拒。
- **校验必须落进 `sanitizeEndpoint`（`src/core/settings.ts:160`）**，不能只留在设置页的
  `originOfLocalEndpoint`：现在 `sanitizeEndpoint` 不限 host，导入一份 JSON 配置就能把整句发到公网
  https 地址。设置页复用同一个判定函数，消灭两套规则。
- 跨机推荐用 `ssh -L` 隧道映射到 `127.0.0.1`（原型本来就这么做），那样连局域网白名单都不用开。

**3) 文案（设置页那一节）**：标题改「语境义挑选（本机服务 · 默认关闭）」；说明改成
「开启后，含生词的**整句**会发到下面这个地址，用于在多个词典义项里挑出最符合语境的。只接受本机与
局域网地址，**绝不发往公网**。服务没起或超时，页面照常显示词典义，不报错。」
地址字段补一句「跨机建议用 ssh 隧道映射到 127.0.0.1」。
现文里指向 `prototype/mt-align/xenc/serve.py` 的说明保留，但注明其交付形态见票 10。

**4) 静默回退确认为终态**：实现已「永不抛错、拿不到就保持词典义」，不再给用户报错。

**5) README 与 ADR**：
- 已写 **`docs/adr/0001-local-only-sentence-context.md`**（决定、被否决的替代方案、后果，含
  「校验要落在设置收敛层」这条）。
- README 要改：首屏「默认纯离线」收窄为「默认离线；语境义挑选需显式开启，且只走本机/局域网」；
  新增一节说明机制与默认关闭；架构树补 `core/sentence.ts`、`core/sense-selector.ts`、
  `background/sense.ts`、`content/sentence-context.ts`、`xenc/serve.py`；测试数 153 → **223**；
  已知限制加「需要自己跑服务」与 mlx 平台限制（指向票 10）。

**6) 弹窗**：本次不加状态显示（`05` 一并决定）。
